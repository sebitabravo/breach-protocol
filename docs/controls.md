# Controles

## Teclado y mouse

| Acción | Control |
| --- | --- |
| Mover / mirar | WASD o flechas / mouse |
| Correr / saltar | Shift / Espacio |
| Disparar / apuntar | Clic izquierdo / mantener clic derecho |
| Recargar / activar un terminal | R / mantener E |
| Cambiar de arma | 1, 2, 3 (si está desbloqueada) |
| Pausar / continuar | Esc |
| Ver ingeniería | F3 |
| Continuar al paso siguiente del tutorial | Enter |
| Omitir todo el tutorial | Retroceso (Backspace) |

El Simulador también avanza el tutorial automáticamente cuando hacés la acción
indicada. Los atajos del tutorial funcionan durante la partida, incluso cuando
el juego tiene capturado el mouse. Si la captura falla al continuar, hacé clic
en la arena para reintentarla.

Al completar el tutorial, el Simulador se pausa y muestra las tres acciones
aprendidas y el tiempo de práctica. Si lo omitís, vas a las mismas opciones,
sin el resumen:

- **Empezar el protocolo** inicia una misión de campaña en el sector recomendado.
- **Seguir practicando** reanuda la misma partida, sin el tutorial.
- **Volver al menú** (también con Esc) sale del Simulador.

Completar u omitir el tutorial guarda que ya lo viste. Podés volver a hacerlo
con **Repetir tutorial** en el menú.

## Pantalla táctil

Movete con el joystick izquierdo y arrastrá en la arena para mirar. Empujá el joystick hasta el borde para correr. Usá los
botones de pantalla para disparar, apuntar, saltar, recargar, cambiar de arma o
pausar. Para activar un terminal, acercate y mantené su botón de interacción.
El tutorial se puede omitir con el botón **Omitir tutorial**.

## Encontrar la terminal

Seguí el rombo menta hasta la terminal iluminada. Si queda fuera de la vista,
la flecha del borde indica hacia dónde girar. Un marcador atenuado indica que
hay cobertura por delante: buscá una ruta alrededor. Cuando aparezca **mantené E**
(**mantené Ⓔ** en táctil), terminá de acercarte y mantené el control hasta llenar
la barra del terminal. Si soltás antes de llenarla, acercate y volvé a mantener
el control: no tenés que repetir los pasos anteriores. El ajuste de movimiento
reducido deja el rombo estático y desactiva la animación de entrada del resumen.
